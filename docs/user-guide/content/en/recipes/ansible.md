# Ansible Adapter (`nws/ansible.adapter`)

`nws/ansible.adapter` is the reference Ansible adapter. It assumes that Ansible is already installed on the host and can be called from Recipes using the `tool.run` action.

---

## Provided Commands

| Command | Description |
|---------|-------------|
| `gen-inventory` | Generate an Ansible Inventory from Node connection information |
| `ansible-playbook` | Execute `ansible-playbook` |
| `ansible-galaxy` | Execute `ansible-galaxy` |

---

## gen-inventory Command

`gen-inventory` is a command that converts the connection information of Nodes managed by Niwashi into an Inventory file readable by Ansible. Always run this command before executing `ansible-playbook`.

The following files are generated in the directory specified by `workdirTpl`:

- `hosts.ini` — Ansible Inventory file (includes an `[all]` section and group sections defined by `params.groups`)
- `ssh_config` — SSH connection configuration file (includes hostname, port, user, and private key path for each Node)

The generated Inventory has `ansible_ssh_common_args='-F ./ssh_config'` set, so specifying `-i hosts.ini` for `ansible-playbook` is all that is needed to connect to Nodes managed by Niwashi.

```yaml
- name: gen-inventory
  action:
    tool.run:
      toolRef: adapter.tool.ansible
      command: gen-inventory
      workdirTpl: "{{ .Paths.work_dir }}"
```

### groups Parameter

The group sections generated by `gen-inventory` are controlled by `params.groups`.

```yaml
spec:
  defaults:
    params:
      groups:
        kube_control_plane:
          - master-node-01
        kube_node:
          - worker-node-01
          - worker-node-02
```

This configuration generates `[kube_control_plane]` and `[kube_node]` sections in `hosts.ini`.

## ansible-playbook Command

Executes the `ansible-playbook` command. Pass arguments using `argvTpl`.

```yaml
- name: run-playbook
  dependsOn: [gen-inventory]
  action:
    tool.run:
      toolRef: adapter.tool.ansible
      command: ansible-playbook
      workdirTpl: "{{ .Paths.work_dir }}"
      argvTpl:
        - -i
        - hosts.ini
        - playbook.yml
        - -e
        - "nginx_port={{ .Params.nginx_port }}"
```

By setting the same directory as `gen-inventory` for `workdirTpl`, the generated `hosts.ini` can be referenced.

---

## ansible-galaxy Command

Executes the `ansible-galaxy` command. Used for installing Roles and similar tasks.

```yaml
- name: install-roles
  action:
    tool.run:
      toolRef: adapter.tool.ansible
      command: ansible-galaxy
      workdirTpl: "{{ .Paths.work_dir }}"
      argvTpl:
        - install
        - -r
        - requirements.yml
```

## Example: Building Kubernetes with Kubespray

The following is an example Recipe that builds a Kubernetes Cluster using Kubespray (see `recipe/kubernetes/kubespray/nws-recipe.yaml`).

```yaml
version: nws.recipe/v1
kind: cluster
metadata:
  id: nws/kubernetes.by.kubespray
  version: "0.0.1"
  description: "Install Kubernetes using Kubespray"
spec:
  provides:
    - name: cluster.kubernetes
      attrs: { by: kubespray }

  requires:
    - adapter.tool.ansible
    - host.tool.git

  workspace:
    mode: persistent     # Retain the Kubespray clone

  defaults:
    params:
      kubespray_url: https://github.com/kubernetes-sigs/kubespray.git
      version: v2.27.1
      become_user: root
      groups:
        kube_control_plane: []
        kube_node: []
        etcd: []

  tasks:
    - name: ensure-dirs
      action:
        exec.local:
          scriptTpl: |
            #!/bin/bash
            set -euo pipefail

            if [ ! -d kubespray ]; then
              git clone {{ .Params.kubespray_url }} kubespray
            fi

            pushd kubespray
            git fetch --all
            git checkout refs/tags/{{ .Params.version }}
            popd

    - name: gen-inventory
      dependsOn: [ensure-dirs]
      action:
        tool.run:
          toolRef: adapter.tool.ansible
          command: gen-inventory
          workdirTpl: "{{ .Paths.work_dir }}/kubespray"

    - name: run-kubespray
      dependsOn: [gen-inventory]
      action:
        tool.run:
          toolRef: adapter.tool.ansible
          command: ansible-playbook
          workdirTpl: "{{ .Paths.work_dir }}/kubespray"
          argvTpl:
            - -i
            - hosts.ini
            - --become-user={{ .Params.become_user }}
            - cluster.yml
```

# Building a Kubernetes Cluster

This page shows a complete example of using Niwashi to build a Kubernetes Cluster.

## Overview

In this example, we build a Kubernetes Cluster with the following configuration:

- **Control Plane**: 1 Node
- **Workers**: 2 Nodes
- **Infrastructure**: Virtual machines generated with Vagrant

---

## Prerequisites

This example assumes that the reference Recipes (Vagrant / Ansible / Kubernetes) have already been obtained into `./recipes`. For instructions on obtaining Recipes, see [Workflow]({{< relref "/getting-started/workflow" >}}).

---

## Complete State File

```yaml
version: nws.state/v1

metadata:
  project: my-k8s-cluster

# Logical configuration
inventory:
  nodes:
    control-plane:
      instanceSelector:
        generator: vms

    worker-01:
      instanceSelector:
        generator: vms

    worker-02:
      instanceSelector:
        generator: vms

  clusters:
    k8s-cluster:
      nodes:
        - control-plane
        - worker-01
        - worker-02
      capabilities:
        - cluster.kubernetes
      params:
        groups:
          kube_control_plane: [control-plane]
          kube_node: [worker-01, worker-02]
          etcd: [control-plane]

# Infrastructure definition
infrastructure:
  generators:
    vms:
      provisioner: infra.vm.driver=vagrant
      params:
        count: 3
        box: ubuntu/jammy64
        cpus: 2
        memory: 2048
```

---

## File Explanation

### metadata

```yaml
metadata:
  project: my-k8s-cluster
```

Sets the project name. This is metadata used to identify the state file.

### inventory.nodes

```yaml
inventory:
  nodes:
    control-plane:
      instanceSelector:
        generator: vms

    worker-01:
      instanceSelector:
        generator: vms

    worker-02:
      instanceSelector:
        generator: vms
```

Defines three Nodes:
- `control-plane`: The Kubernetes control plane Node
- `worker-01`, `worker-02`: Kubernetes worker Nodes

All Nodes use instances generated by the `vms` Generator.

### inventory.clusters

```yaml
inventory:
  clusters:
    k8s-cluster:
      nodes:
        - control-plane
        - worker-01
        - worker-02
      capabilities:
        - cluster.kubernetes
      params:
        groups:
          kube_control_plane: [control-plane]
          kube_node: [worker-01, worker-02]
          etcd: [control-plane]
```

Defines the Kubernetes Cluster:
- **nodes**: The three Nodes joining the Cluster
- **capabilities**: `cluster.kubernetes` to build a Kubernetes Cluster
- **params.groups**: Defines the role of each Node
  - `kube_control_plane`: Control plane Node
  - `kube_node`: Worker Nodes
  - `etcd`: Nodes running etcd

### infrastructure.generators

```yaml
infrastructure:
  generators:
    vms:
      provisioner: infra.vm.driver=vagrant
      params:
        count: 3
        box: ubuntu/jammy64
        cpus: 2
        memory: 2048
```

Generates three virtual machines using Vagrant:
- **count**: Generate 3 VMs
- **box**: Use Ubuntu 22.04 LTS
- **cpus**: 2 cores per VM
- **memory**: 2 GB of memory per VM

## Execution Steps

### 1. Create the State File

Save the content above as `k8s-cluster.yaml`.

```bash
cat > k8s-cluster.yaml <<'EOF'
version: nws.state/v1

metadata:
  project: my-k8s-cluster

inventory:
  nodes:
    control-plane:
      instanceSelector:
        generator: vms
    worker-01:
      instanceSelector:
        generator: vms
    worker-02:
      instanceSelector:
        generator: vms

  clusters:
    k8s-cluster:
      nodes:
        - control-plane
        - worker-01
        - worker-02
      capabilities:
        - cluster.kubernetes
      params:
        groups:
          kube_control_plane: [control-plane]
          kube_node: [worker-01, worker-02]
          etcd: [control-plane]

infrastructure:
  generators:
    vms:
      provisioner: infra.vm.driver=vagrant
      params:
        count: 3
        box: ubuntu/jammy64
        cpus: 2
        memory: 2048
EOF
```

### 2. Create the Plan

```bash
nwsctl plan --recipe-dir ./recipes -t k8s-cluster.yaml
```

Niwashi plans the following operations:
1. Generate 3 VMs with Vagrant
2. Assign each VM to a Node
3. Build the Kubernetes Cluster

### 3. Execute the Plan

```bash
nwsctl apply --plan plan.json --recipe-dir ./recipes
```

Niwashi executes the Plan and builds the Kubernetes Cluster.

### 4. Verify

Verify that the Cluster was built correctly:

```bash
# Check Node status
nwsctl ssh control-plane -- kubectl get nodes

# Check Pod status
nwsctl ssh control-plane -- kubectl get pods --all-namespaces
```

## Environment-Specific Configuration

An example of using different configurations for production and development environments.

### File Split

```
├── base-k8s.yaml       # Logical configuration (shared)
├── infra-dev.yaml      # Development environment infrastructure
└── infra-prod.yaml     # Production environment infrastructure
```

### base-k8s.yaml (Logical Configuration)

```yaml
version: nws.state/v1

metadata:
  project: k8s-cluster

inventory:
  nodes:
    control-plane: {}
    worker-01: {}
    worker-02: {}

  clusters:
    k8s-cluster:
      nodes:
        - control-plane
        - worker-01
        - worker-02
      capabilities:
        - cluster.kubernetes
      params:
        groups:
          kube_control_plane: [control-plane]
          kube_node: [worker-01, worker-02]
          etcd: [control-plane]
```

### infra-dev.yaml (Development Environment)

```yaml
version: nws.state/v1

infrastructure:
  generators:
    vms:
      provisioner: infra.vm.driver=vagrant
      params:
        count: 3
        box: ubuntu/jammy64
        cpus: 2
        memory: 2048
```

### infra-prod.yaml (Production Environment)

```yaml
version: nws.state/v1

infrastructure:
  generators:
    prod-servers:
      provisioner: external-instance
      params:
        instances:
          k8s-cp:
            connection:
              ssh:
                address:
                  host: k8s-cp.example.com
                  port: 22
                  user: ubuntu
          k8s-worker-01:
            connection:
              ssh:
                address:
                  host: k8s-worker-01.example.com
                  port: 22
                  user: ubuntu
          k8s-worker-02:
            connection:
              ssh:
                address:
                  host: k8s-worker-02.example.com
                  port: 22
                  user: ubuntu
```

### Switching Between Environments

```bash
# Development environment
nwsctl plan --recipe-dir ./recipes -t base-k8s.yaml -t infra-dev.yaml

# Production environment
nwsctl plan --recipe-dir ./recipes -t base-k8s.yaml -t infra-prod.yaml
```

## Customization

### Adding More Worker Nodes

An example of increasing worker Nodes to three:

```yaml
inventory:
  nodes:
    control-plane: {}
    worker-01: {}
    worker-02: {}
    worker-03: {}  # Added

  clusters:
    k8s-cluster:
      nodes:
        - control-plane
        - worker-01
        - worker-02
        - worker-03  # Added
      params:
        groups:
          kube_control_plane: [control-plane]
          kube_node: [worker-01, worker-02, worker-03]  # Added
          etcd: [control-plane]

infrastructure:
  generators:
    vms:
      params:
        count: 4  # Changed from 3 to 4
```

### Increasing Resources

An example of increasing the resources of each VM:

```yaml
infrastructure:
  generators:
    vms:
      provisioner: infra.vm.driver=vagrant
      params:
        count: 3
        box: ubuntu/jammy64
        cpus: 4      # Changed from 2 to 4
        memory: 4096  # Changed from 2048 to 4096
```

### HA Cluster Configuration

A high-availability configuration with three Control Plane Nodes:

```yaml
inventory:
  nodes:
    cp-01: {}
    cp-02: {}
    cp-03: {}
    worker-01: {}
    worker-02: {}
    worker-03: {}

  clusters:
    k8s-cluster:
      nodes:
        - cp-01
        - cp-02
        - cp-03
        - worker-01
        - worker-02
        - worker-03
      capabilities:
        - cluster.kubernetes
      params:
        groups:
          kube_control_plane: [cp-01, cp-02, cp-03]
          kube_node: [worker-01, worker-02, worker-03]
          etcd: [cp-01, cp-02, cp-03]

infrastructure:
  generators:
    vms:
      provisioner: infra.vm.driver=vagrant
      params:
        count: 6
        box: ubuntu/jammy64
        cpus: 2
        memory: 2048
```

## Troubleshooting

### VMs Fail to Start

**Problem**: Instance generation with Vagrant fails.

**Solution**:
1. Verify that Vagrant is correctly installed
2. Verify that virtualization is enabled (BIOS settings)
3. Verify that there is sufficient memory

### Kubernetes Cluster Build Fails

**Problem**: An error occurs during the Cluster build process.

**Solution**:
1. Verify that Node resources are sufficient (especially memory)
2. Check the Recipe logs
3. Verify network connectivity
